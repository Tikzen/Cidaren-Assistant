词达人小助手 1.1.0 正式版（Windows x64 便携版）。完整解压后运行 `CidarenAssistant.exe`，无需安装 Python。未进行代码签名。

- **feat**：新增默认关闭的 AI 答题兜底，预设 DeepSeek Flash，支持自填 OpenAI 兼容服务、模型与 API Key。
- **feat**：查词失败、策略未命中和多个候选需语境消歧时，尝试 AI 后再进入普通兜底。已有确定答案不额外请求 AI。
- **fix**：将策略内部的随机选项、固定第三项和未命中的拼写出口统一交给兜底流程，避免绕过 AI。
- 设置单次等待和每项任务调用上限；连续失败会停用本项 AI，用户停止后不提交迟到结果。AI 输出会核对选项、词形标签、拼写长度和空位顺序，仍以平台判分为准。
- AI 配置在「设置 → 首选项 → AI 兜底」。密钥仅保存在本机用户目录；不会向 AI 发送词达人 Token 或账号信息。使用 AI 可能增加耗时和接口费用。

已有版本可使用「帮助 → 检查更新」；手动升级时保留原 `config/` 和 Token 文件。答案库、词表、错题记忆、缓存及队列记录会保留。

包含离线回归和 Windows 打包自检。未使用用户真实付费 API Key 测量 AI 的在线正确率提升。日志分析和使用方式见仓库 `docs/AI兜底与日志分析.md`。
