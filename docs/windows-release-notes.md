词达人小助手 1.1.1 正式版（Windows x64 便携版）。完整解压后运行 `CidarenAssistant.exe`，无需安装 Python。未进行代码签名。

- **feat**：新增可选 AI 答题兜底，预设 DeepSeek Flash，支持自填 OpenAI 兼容接口、模型和 API Key。查词失败、策略未命中或候选需语境消歧时尝试 AI，已有确定答案不额外调用。
- **feat**：AI 开关位于主界面「开始队列」上方，旁边感叹号支持悬停提示。未完成配置和测试保存时，会弹窗提醒并拒绝勾选。
- **feat**：首选项新增「测试模型」，测试成功后才能保存 AI 配置；地址、模型或密钥变化后需要重新测试。未通过测试时「应用／确定」显示灰色，点击会提示先测试。
- **fix**：模型不可用、请求失败或超时会退回普通猜答。同单元连续三次 AI 尝试失败后，本次软件会话内该单元不再调用 AI，后续提分或重新入队不会重置；下一单元重新尝试。成功返回可用答案会清零连续失败计数。
- **fix**：增加 AI 开关文字与提示图标的间距，避免重叠。
- 将策略内部的随机选项、固定第三项和未命中的拼写出口统一交给兜底流程。保留单次等待、每项任务调用上限和取消等待；AI 输出校验选项、词形标签、长度和空位顺序，仍以平台判分为准。

AI 默认关闭，在「设置 → 首选项 → AI 兜底」配置并测试后，保存配置，再到主界面按需勾选。测试会发送一道简单示例题，可能产生少量接口费用。密钥仅保存在本机用户目录，不向 AI 发送词达人 Token 或账号信息。

已有版本可使用「帮助 → 检查更新」；手动升级时保留原 `config/` 和 Token 文件。答案库、词表、错题记忆、缓存及队列记录会保留。

包含离线回归和 Windows 打包自检；未使用用户真实付费 API Key 测量 AI 的在线正确率提升。详细说明见仓库 `docs/AI兜底与日志分析.md` 与图文使用教程。
