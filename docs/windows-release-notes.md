词达人小助手 1.0.0 正式版（Windows x64 便携版），解压完整文件夹后运行 `CidarenAssistant.exe`，无需安装 Python。未进行代码签名。

- **fix**：修复未初始化班级任务（`task_id=-1`）和任务 ID 变化后仍使用旧 ID 的问题，避免选词后提示「加载任务信息失败」。旧失败队列项可核对进度后直接重试。
- **fix**：修复多开清理日志时偶发启动失败。
- **fix**：取消单题自动跳过；没有确定答案时按题型猜答，普通答题、续做、从头开始和重做提分统一生效。兼容模式继续为解析异常提供猜答兜底；题目缺少必要作答结构时明确停止当前项并继续队列。
- **fix**：Windows 更新助手使用 .NET 内置 SHA256 校验，避免 PowerShell 模块路径差异导致校验失败。
- **feat**：帮助菜单新增可应用的检查更新入口，比较文件内容、下载校验、保留本地数据；Windows 退出后替换差异文件并自动重启。
- **fix**：检查更新页面分别显示当前与最新文件版本；源码版读取实际版本号，不再用提交哈希作为版本号。修复进度文字被过薄的进度条裁剪，独立显示进度状态。
- 更新时需先结束任务、关闭其他多开和 Token 获取窗口。保留配置、Token、答案库、错题记忆、缓存及队列，不自动恢复执行任务。

已有支持自动更新的版本可使用「帮助 → 检查更新」。更早版本仍需手动下载 ZIP；手动升级时备份并保留原 `config/` 和 Token 文件，不要用新包默认配置覆盖。

附件包括 ZIP、逐文件更新清单和 SHA256 校验文件。通过 Windows 离线回归及实际 PowerShell 更新/重启测试，并检查冻结后的窗口、本地模型、多开启动和内置捕获组件；未登录用户账号执行在线任务。
