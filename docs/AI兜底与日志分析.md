# AI 兜底与本机日志分析

## 日志中发现了什么

本次查看项目 `log/logs/`，选取三份包含连续真实判分记录的运行日志。它们记录于 **2026-11-12**；11 月 13 日以后的多份短日志主要来自离线回归测试，未混入统计。旧日志不能代表当前 1.0.0 或新增 AI 功能的准确率。

三份日志共 **2,755 次判分、198 次判错**。这里统计的是提交次数，包含续做和重做，不是不同单词数，也不能据此推算最终成绩。

| 题型 | 判错次数 | 占全部判错 |
| --- | ---: | ---: |
| 语境选义（mode 11） | 145 | 73.2% |
| 其他释义选择（mode 22） | 36 | 18.2% |
| 单词补全（mode 51） | 16 | 8.1% |
| 短语填空（mode 32） | 1 | 0.5% |

主要问题是词义和语境消歧：词典返回多个释义时，原策略按选项顺序采用首个匹配，没有充分结合当前例句和中文语义。例如 `morals` 在“传统道德”的语境下应取名词义，日志里却匹配到了形容词“有道德的”。因此，只在服务器接口报错后请求 AI，覆盖不了主要问题。

在 198 次判错中，有 **43 次**在当前题的日志片段中明确出现“匹配失败”“随机提交”“找不到答案”等猜测标记。这个统计与题型表有重叠。还有拼写流程返回不符合当前题要求的候选、短语词位和选项不匹配等问题。卡片接口也确实出现了 `120` 卡片数据错误和 `10005` 未找到数据，但这些并非本批日志中判错的主要来源。

此结论基于历史日志和当前代码路径核对。没有使用日志内的账号或 Token 重新答题，未上传原始日志或个人数据。

## 使用 AI 兜底

进入 **设置 → 首选项 → AI 兜底**。

1. 默认关闭。预设是 **DeepSeek Flash**：基础地址 `https://api.deepseek.com`，模型名称 `deepseek-flash`。
2. 填入自己的 API Key，点击「测试模型」。测试会发送一道简单示例题；只有测试成功，「应用／确定」才会恢复正常。未测试或测试失败时按钮显示灰色，点击会提醒先测试。
3. 保存后，在主界面「开始队列」按钮上方勾选 **AI 兜底**。旁边的感叹号可悬停查看提示。未配置完整或未通过测试保存时，会弹窗提醒并拒绝勾选。
4. 自定义服务选择「自定义 OpenAI 兼容模型」，填写基础地址和模型名称。基础地址可带 `/v1`，软件会调用 `/chat/completions`；也接受完整的该接口地址。一次使用一个模型配置。
5. 默认为单次最多等待 **20 秒**、每个队列任务最多调用 **30 次**，可自行调整。不同账号、多开窗口各自按队列任务计数。
6. 新设置在下一次启动队列时读取，不中途改变运行中的任务。

接口采用 [Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/) 格式；DeepSeek Flash 预设关闭思考模式并请求 JSON 输出。自定义模型需支持兼容的 Chat Completions 接口及 `max_tokens` 参数。

## 触发顺序与限制

优先使用已有的错题记忆、答案库、词表及词达人查词。以下情况才请求 AI：

- 查词卡片缺失、无法加载，或启用 AI 后查词网络请求有限重试仍失败。
- 原有策略没有确定答案。
- 多个词义同时命中，或多个拼写候选都满足前缀、长度，仍需结合句意判断。

确定的已有答案不额外请求 AI。AI 返回内容必须通过当前题型的本地校验：选项下标不能越界；词形选择转换为平台原始标签；短语必须来自当前选项且覆盖全部空位；拼写必须满足前缀、长度及空位顺序。

AI 不可用、超时、返回空内容或格式不合规时，保留原有可用候选，或继续普通猜答兜底。关闭兼容模式时，未被 AI 恢复的解析异常仍会明确停止当前项。账号失效、安全验证、提交结果不明和其他业务错误不会被 AI 覆盖。

修改地址、模型或密钥后，必须重新测试成功才能保存；已测试过且配置内容未变，无需重复测试。首选项的其他设置不要求先配置 AI。

每题不会无限请求；相同题目数据和已判错候选不变时复用本任务内的请求结果，失败也不会反复请求。同一单元连续三次 AI 请求失败或输出不可用后，本次软件会话中该单元不再请求 AI；同单元的后续队列项、提分轮次和重新开始队列也不会重置熔断，进入下一单元重新尝试。成功取得可用答案会清零连续失败计数，普通平台判错不算 AI 接口失败。鉴权、接口地址、限流、超时等异常都回退普通猜答，不因 AI 不可用中断队列。停止任务会取消等待，迟到的 AI 返回不会提交。

AI 答案不是标准答案，可能仍然出错。本功能不会直接把 AI 返回写入共享标准答案库或查词缓存；后续由词达人的实际判分反馈更新现有记忆机制。尚未使用用户的真实付费密钥测量正确率提升。

## 本地配置与发送内容

AI 配置和密钥保存在当前用户数据目录下的 `ai-settings.json`，不写入项目的 `config/config.json`，不进入 Git、更新包或日志。该文件为本地明文配置；macOS/Linux 限制为当前用户读写，Windows 使用当前用户数据目录。

请求只包含当前题干、释义、选项、前缀、长度、必要词表和已判错候选，不包含词达人 Token、账号信息或任务标识。AI 采用独立会话，不复用词达人的认证头、Cookie 和临时系统代理。
