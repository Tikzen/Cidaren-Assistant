# 词达人小助手

**2026 持续维护中，更快、更强、更稳定的词达人自动助手。**

词达人小助手是一款用于**自动完成词达人学习任务与测试任务**的桌面工具，支持自定义任务队列、自动答题和错题记忆。对于支持重做并允许自选单词的学习任务，可在完成刷题后**自动重做错词、未满分词，持续提分直至满分或达到停止条件**，减少重复操作。

本项目魔改自 **[ularch/Easy_Cidaren](https://github.com/ularch/Easy_Cidaren)**，在原项目基础上持续优化答题策略、运行效率、异常恢复和桌面操作体验，并新增可自定义顺序的任务队列与重做提分功能。目前由 [Tikzen](https://github.com/Tikzen) 独立维护，感谢原作者及上游贡献者提供的基础实现。

## 在原项目基础上的亮点

### 更迅速：缩短等待，减少重复工作

优化实际题间等待，使用随机节奏，在提速的同时兼顾风控风险与运行稳定性。配合模型复用、查词缓存和跨重启持久化，减少重复加载、重复查词等开销。

提速也来自减少无效重跑：临时网络问题优先在当前请求恢复，不因一次错误就从任务开头重来；一键满分会续做已有进度，已经完成的任务直接进入提分。

### 更稳定：减少报错和重试，提高任务完成成功率

针对实际运行中遇到的连接中断、词形还原失败、单词卡片不可用、答案缺失及解析异常补充处理策略，减少原版中报错后从头重试、在相同位置再次失败而浪费大量时间的情况。

- **请求原地重试**：可恢复的网络故障在当前请求有限重试，保留任务进度。
- **兼容模式继续答题**：缺失答案或部分解析异常可尝试猜测，减少整项任务直接中断。
- **区分异常原因**：当前题的数据缺失、账号失效、安全验证和提交结果不明分别处理。
- **队列继续执行**：无法重做、服务端不允许选词或当前项失败时，记录原因并继续其他可执行项。
- **有界运行**：限制请求次数、提分轮数、连续无进展轮数和执行用时，避免无限报错、无限重试。

### 正确率更高：策略覆盖更广，减少同类错误

围绕实际课程中的题型与数据差异补充策略，减少因词形、选项顺序和模板格式变化产生的误答。

- **词形与原型核对**：模型未能正确还原时，进一步核对当前单元词表，处理 `satisfied → satisfy`、`hung → hang` 等情况。
- **短语与填空适配**：支持固定词过滤、多词选项、连字符词位、模板空白差异及词典短语例子的提取。
- **选项顺序适配**：保留服务端原始选项位置，避免内部排序导致提交下标错误。
- **全任务错题记忆**：记录服务端返回的标准答案，按题型、题干和释义复用，减少重复犯错；程序重启后仍保留。
- **提分阶段的补充策略**：结合词典上下文、词形约束和已判错选项排除，逐步缩小候选范围。

### 自定义队列：自己决定做哪些、怎么做、先做谁

所有任务统一通过队列执行，可以混合安排不同执行方式。

- 多选任务加入队列，或**一键添加全部**。
- **拖动排序**，也可上移、下移等待中的任务。
- 支持暂停、继续、中止、移除、手动重试和结果查看。
- 原「开始任务」先把所选任务加入队尾，再按顺序执行。
- 原「一键刷题」由完整队列控制替代。
- 队列顺序持久化，异常退出后保留等待项，中断项待核对。

| 执行方式 | 适用场景与行为 |
| --- | --- |
| **从头开始** | 希望重新执行完整学习任务；服务端允许时重新完整选词。 |
| **重做提分** | 仅完成度达到 **100%** 的学习任务可勾选，只处理错词、未满分词。 |
| **一键满分** | 未完成任务先续做刷题，再自动进入提分；已完成任务直接提分，已满分且无未满分词则直接完成。 |

**完成度 100% 不等于成绩 100 分。** 重做提分和一键满分需要任务支持重做并允许自选单词。提分会增加耗时，建议用于有成绩要求的任务；不支持时会说明原因并跳过，满分目标仍受题库覆盖和停止条件约束。

### 多开与共享积累

支持打开多个独立窗口，不同账号可以并行运行，同一账号避免重复执行。答案库、错题记忆、词表池和查词缓存由各窗口共用，学习结果持续积累。

保留内置 Token 获取方式。业务会话从创建起直连，获取 Token 使用的临时系统代理不会让队列自动暂停；运行中获取新 Token 也不会替换当前执行账号。

## 实际使用效果

以下为具体任务中的实际使用与开发迭代记录，不是统一条件下的性能基准。

### 580 词任务使用反馈

| 指标 | 原先表现 | 优化后表现 |
| --- | --- | --- |
| 完成用时 | 约 1 小时 | 约 **1400 秒（23 分 20 秒）**，耗时减少约 **61%** |
| 错词数 | 40 余词 | 约 30 词 |
| 成绩 | 92 分 | **94 分** |

随机答题节奏等优化带来的提速尤其明显；后续答题策略优化减少错词、提高成绩时，用时基本保持不变。实际使用中，报错后反复从头重跑的情况明显减少，任务完成更顺畅。

### 重做提分实测

- **8 个 CET4 班级自学任务、共 240 词**：全部达到 **100 分**，重新读取服务器数据确认没有未满分词。[验证记录](docs/redo-until-full-implementation.md)
- **新世纪3 U5 Text A、U6 Text A，共 100 词**：修复后均达到 **100 分**，任务分数、单元分数和单词状态均已独立复核。U6 最后一题包含人工核对后补入共享答案库的短语候选。[修复与验证记录](docs/unit-card-repair.md)
- 已有 **149 项离线回归测试通过记录**，覆盖请求恢复、答题策略、队列、多开、共享缓存及异常边界。

这些结果展示了特定任务中的改进效果，不代表所有课程都具有相同提速比例或都能自动达到满分。

## 运行

当前提供源码运行，桌面 UI 仍在优化，macOS 独立安装包尚未发布。

使用 Python 3.12 创建环境、安装依赖后启动：

```sh
git clone https://github.com/Tikzen/Cidaren-Assistant.git
cd Cidaren-Assistant
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Windows 可使用 Python 3.12 创建虚拟环境，并通过 `.venv\Scripts\python.exe` 安装依赖、运行 `main.py`。

已有开发环境可以直接运行：

```sh
.venv/bin/python main.py
```

登录后选择任务、加入队列、调整顺序，再开始执行。需要单独提分时，勾选完成度 100% 的学习任务；需要自动衔接刷题和提分时，使用一键满分。
